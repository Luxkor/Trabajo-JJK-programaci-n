🎯 3 MODOS DE CONEXIÓN DISPONIBLES
═══════════════════════════════════════════════════════════════════

1️⃣  RED LOCAL (LAN) — Ya existía ✓
    arrancar.bat → Opción 1
    • Ambos PC en misma red WiFi/Ethernet
    • Rápido, bajo latency
    • SIN firewall complicado
    ✓ Recomendado para jugar localmente

2️⃣  LOCALTUNNEL — Ya existía ✓
    arrancar.bat → Opción 2
    • URL pública HTTPS automática
    • Funciona desde cualquier red
    • Requiere internet constante
    ✓ Ideal para amigos en internet

3️⃣  PEER-TO-PEER (WebRTC) — ✨ NUEVO
    arrancar.bat → Opción 3
    • Conexión directa entre jugadores
    • Servidor solo para signaling (setup)
    • Bajo latency una vez conectados
    • Escalable: muchas partidas sin sobrecargar
    ✓ Máximo rendimiento

═══════════════════════════════════════════════════════════════════

OPCIÓN 1 - Red Local (LAN)
──────────────────────────
PC 1 (Host):
  1. Ejecuta: arrancar.bat
  2. Elige: Opción 1
  3. Copia IP automaticamente
  4. Servidor en: http://localhost:3000

PC 2 (Cliente):
  1. Abre navegador
  2. Ingresa: http://[IP-DEL-HOST]:3000
  3. Haz clic JUGAR
  4. Elige: Servidor (Socket.io)
  5. Completar lobby normalmente

PC 2 (Cliente):
  1. Recibe URL
  2. Abre en navegador: https://xyz-123-abc.loca.lt
  3. Haz clic JUGAR
  4. Elige: Servidor (Socket.io)
  5. Completar lobby normalmente

Esquina superior derecha de la pantalla:

🔴 Rojo = Desconectado
🟡 Amarillo (pulsante) = Conectando/Negoción P2P
🟢 Verde (pulsante) = Conectado y listo


🔐 SEGURIDAD
═══════════════════════════════════════════════════════════════════

• WebRTC usa SRTP — Tráfico encriptado
• STUN servers — Solo para negociación
• Signaling local — No datos sensibles en servidor central
• Socket.io over HTTPS — Si se usa localtunnel
• No hay centralización de datos con P2P
